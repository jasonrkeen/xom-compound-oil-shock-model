# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-07-23

### Added

- Four compound oil-supply disruption scenarios.
- Physical supply-gap and convex Brent-price stress layer.
- ExxonMobil segment-earnings and free-cash-flow bridge.
- Three-method equity valuation ensemble.
- Reproducible Monte Carlo simulation with P10, median, and P90 outputs.
- Interactive Streamlit dashboard.
- Four-page executive report with a benefit-flip threshold map.
- Optional live XOM, Brent, and WTI observations with documented fallbacks.
- Source and method log, automated tests, and GitHub Actions workflow.
